## 一、快捷键操作
### 1.1 使用键盘移动光标

<img src="https://img.pianone.dpdns.org/file/FOPHT4" width="200" alt="vim上下左右.png">

在Windows中, 常用快捷键对光标快速定位的人都应该离不开 `ctrl` `shift` `home/end` `↑/↓/←/→` 这些按键/组合键.  但在vim中会发现**移动光标(左,下,上,右)**的按键分别是**`h` `j` `k` `l`**. 

有人说是因为 `Bill Joy`  在创建 `vi` 文本编辑器时, 用的机器机器是 [`ADM-3A`](http://www.aeagean.com/2019/04/13/unix/unix_why_vim_uses_hjkl_to_move_cursors/)  终端机,这台机器就是把 `h` `j` `k` `l` 键作为方向键. ( `vim`编辑器就是后来`Bram Moolenaar`基于`vi`开发的). 对于一个没有方向键的终端, 把手从键盘拿开去够鼠标, 当然没有直接按下键盘移动更加高效. 

也有人说, `vim`编辑器出现以前, 各类键盘有所不同, 以前的键盘是不含如今多个工作区的键盘, 即: (含数字区、上下左右键区),  故含数字区、上下左右键区可能在某些情况下不生效! (如: 插入模式下, 数字区不生效! )
总之, `vim`的设计初衷可能是为了在各种终端和键盘布局下提供一致的操作体验, 掌握 **`h` `j` `k` `l`** 这些键的使用, 对于提高编辑效率和适应各种终端环境是非常重要的, 毕竟什么键盘也不太可能少了这几个键.

上下左右仅仅是光标移动的开始, 下列快速移动转跳都可以使用对应vim快捷键进行替换. 

|       操作       |           Vim 快捷键           | Windows 普通文本编辑器 快捷键 |
| :--------------: | :----------------------------: | :---------------------------: |
| 移动到上一个单词 |              `b`               |         `Ctrl` + `←`          |
| 移动到下一个单词 |              `w`               |         `Ctrl` + `→`          |
|    移动到行首    | `0`/`^` |            `Home`             |
|    移动到行尾    | `$`/`g_` |             `End`             |
|  移动到文件顶部  |              `gg`              |        `Ctrl` + `Home`        |
|  移动到文件底部  |              `G`               |        `Ctrl` + `End`         |

使用场景：

- **跳到行首和行尾**：当你需要修改当前行的开头或结尾时, 可以使用 `0` 和 `$`.
- **快速浏览文件顶部和底部**：当你需要查看文件的开头或结尾时,`gg` 和 `G` 是非常便捷的命令.

> 值得注意的是光标移动到**行首尾**的快捷键有很多, `Home`/`End`和`0`/`$`效果是一样的, 不多赘述, 具体说一下`^`/`g_`和`0`/`$`的区别: 
> 
> 将光标移到当前行`第一个`/`最后一个`**非空白字符**上:  在一行文本中,光标会移动到这一行中`行首`/`行尾`不是空格、制表符或其他空白字符的地方.
> 举个例子: 如果一行文本是     Hello, World!      , 其中文本前后都有空格(空白字符), 使用`^`/ `g_` 会将光标移动到`H`/`!`**非空白字符**上, 使用`0`/`$`会将光标移动`第一个`/`最后一个`**空格**上. 
>
> 相比于`Home` / `End` + `ctrl + →` /  `ctrl + ←`的组合操作,  短而快的`^` / `g_`的优势就体现出来了🐶.

接下来是一些快速翻页、转跳行的操作

|          操作          |  Vim 快捷键  | Windows 普通文本编辑器 快捷键  |
| :--------------------: | :----------: | :----------------------------: |
|        向前一页        | `Ctrl` + `b` |           `Page Up`            |
|        向后一页        | `Ctrl` + `f` |          `Page Down`           |
|        向前半页        | `Ctrl` + `u` |       --        |
|        向后半页        | `Ctrl` + `d` |       --        |

|     跳转到下一段落     |     `}`      |        --        |
|     跳转到上一段落     |     `{`      |        --        |
| 跳转到上一次编辑的位置 |     ```      |        --        |

### 1.4 系统剪贴板与寄存器操作

很多初学者在 Vim 里经常会遇到一个痛点：在 Vim 里复制的文本无法粘贴到系统其他软件（如浏览器、微信、VSCode）中，或者外部复制的代码用 `p` 粘贴不进 Vim。这是因为 Vim 默认使用的是内部寄存器（无名寄存器 `"`）。

要在 Vim 与操作系统剪贴板之间无缝流转，或者管理多份剪贴内容，就需要用到**系统剪贴板寄存器**与**寄存器查看命令**。

| 操作 | Vim 命令 / 快捷键 | 功能说明 |
| :--- | :--- | :--- |
| 查看所有寄存器 | `:reg` | 查看当前所有寄存器中缓存的内容（包括历史复制、删除的内容） |
| 查看指定寄存器 | `:reg +` 或 `:reg "` | 查看系统剪贴板或默认寄存器的内容 |
| 粘贴系统剪贴板内容（光标后） | `"+p` | 将系统剪贴板中的内容粘贴到光标之后 |
| 粘贴系统剪贴板内容（光标前） | `"+P` | 将系统剪贴板中的内容粘贴到光标之前 |
| 复制选中文本到系统剪贴板 | `"+y`（可视模式下） | 将当前选中的内容写入操作系统的系统剪贴板 |
| 复制整行到系统剪贴板 | `"+yy` | 将当前整行内容写入系统剪贴板 |

> **提示**：
> 1. `"+` 指的是系统的“剪贴板寄存器”（Clipboard Register）。在 Linux X11 环境下，`"*` 通常指鼠标选区选择缓冲区，而 `"+` 指全局剪切板（`Ctrl+C / Ctrl+V`）。
> 2. 如果执行 `"+y` 或 `"+p` 没反应，可在终端通过 `vim --version | grep clipboard` 检查 Vim 是否支持剪贴板特性（如果有 `+clipboard` 则支持，若为 `-clipboard` 则需安装支持特性的版本，如 Linux 上的 `vim-gtk` / `vim-gnome`）。

使用场景：

- **跨软件复制代码**：在网页或文档复制了配置，进 Vim 按 `"+p` 粘贴；在 Vim 选中代码按 `"+y`，直接去浏览器发帖提问。
- **找回刚才误删/覆盖的文本**：当多次删除操作覆盖了默认剪贴板时，输入 `:reg` 可以查看编号寄存器 `0~9` 中保留的历史删除与复制记录，通过 `"3p` 即可按需找回。

### 1.5 可视块模式（强大的列编辑）

在日常写代码或处理配置文件时，经常遇到“多行批量加注释”、“多行对齐”、“批量删除某一列字符”的需求。普通文本编辑器可能需要配合鼠标多光标选择，而在 Vim 中，只需要 **可视块模式（Visual Block）** 即可轻松完成。

通过按快捷键 `Ctrl` + `v` 进入可视块模式后，使用方向键（`h/j/k/l`）框选出一块矩形区域，随后可以执行以下常用操作：

| 操作分类 | 快捷键 / 命令 | 操作效果说明 |
| :--- | :--- | :--- |
| **多行行首插入** | `I`（大写） | 在选中块的最左侧进入插入模式，输入内容后按 `Esc`，选中的所有行都会生效 |
| **多行末尾追加** | `A`（大写） | 在选中块的最右侧追加内容，输入后按 `Esc` 批量生效 |
| **删除块** | `d` 或 `x` | 快速剪切/删除选中的矩形块区域 |
| **复制与粘贴块** | `y` / `p` | 复制整块矩形文本，并在目标光标处按列粘贴 |
| **缩进与反缩进** | `>` / `<` | 将选中块对应的行整体向右缩进或向左缩进 |
| **大小写转换** | `U` / `u` / `~` | 将选区内容批量转换为：全大写 / 全小写 / 大小写反转 |

使用场景：

- **批量多行注释**：`Ctrl+v` 垂直选中多行行首 -> 按大写 `I` -> 输入注释符号（如 `// ` 或 `# `） -> 按两次 `Esc`，所选行的行首瞬间全部加上注释！
- **批量取消注释**：`Ctrl+v` 框选注释符号所在列 -> 按 `d` 即可瞬间删除多行注释。

### 1.6 外部 Shell 命令交互与内容读写

Vim 并非一座与世隔绝的孤岛。你可以不退出 Vim 直接调用外部终端命令，甚至将外部命令的输出直接“导入”到当前编辑的文档中。

| 核心命令 | 语法示例 | 实际用途与场景 |
| :--- | :--- | :--- |
| **执行外部命令** | `:!<command>` | 如 `:!ls -lh` 或 `:!python %`，临时执行 shell 命令，按回车返回 Vim |
| **读入外部文件** | `:r <filename>` | 如 `:r header.txt`，将外部文件的内容直接插入到当前光标所在行的下方 |
| **读入命令输出** | `:r !<command>` | 如 `:r !date`，执行外部命令并将终端输出文本直接插入到当前行下方 |
| **多命令串联执行** | `:<cmd1> \| <cmd2>` | 使用 `\|` 管道分隔符，一次性在 Vim 命令行顺序执行多条命令（例如 `:w \| !python %`） |

> **提示**：在 Vim 命令行中，`%` 符号代表“当前正在编辑的文件名”。

使用场景：

- **代码快速运行**：写完脚本直接在 Vim 输入 `:!python %`，原地查看输出结果，无需另开窗口。
- **生成时间戳/机器信息**：在写文档或博客头信息时，输入 `:r !date "+%Y-%m-%d %H:%M:%S"`，即可直接将当前时间自动打在文档中。
- **一键保存并运行**：使用 `:w | !python %`，保存的同时立即运行当前代码。

### 1.7 查找与批量替换命令

Vim 的替换功能极其强大，核心命令是 `:s`（substitute）。通过配合正则表达式、作用范围和确认参数，可以高效地完成复杂的全局重构。

**1. 基本替换格式**：
- `:s/old/new/`：仅替换当前行【第一个】匹配的 old
- `:s/old/new/g`：替换当前行【所有】匹配的 old（g 表示 global 全行）
- `:%s/old/new/g`：替换【整个文件】所有匹配的 old（% 表示整篇文档）
- `:%s/old/new/gc`：整个文件替换，但每次替换前提示确认（c 表示 confirm，按 `y` 确认、`n` 跳过、`a` 全部替换、`q` 退出）

**2. 指定范围替换**：
- `:10,20s/old/new/g`：仅在第 10 行到第 20 行之间执行替换
- `:.,$s/old/new/g`：从当前光标行（`.`）一直替换到文件末尾（`$`）
- `:'<,'>s/old/new/g`：对可视模式选中的行范围执行替换（在可视模式下按 `:` 会自动带出 `'<,'>`）

**3. 实用技巧：批量行首 / 行尾追加**：
- `:%s/^/prefix_/g`：在每一行的【行首】追加前缀 `prefix_`
- `:%s/$/;/g`：在每一行的【行尾】追加分号 `;`
- `:5,15s/^/# /g`：给第 5 到 15 行批量在行首添加注释符 `#`

使用场景：

- **批量构造 SQL/列表**：有一批导出的纯 ID 列表，想加上单引号和逗号，只需 `:%s/^/'/g` 配合 `:%s/$/',/g`，秒级搞定。
- **代码重构重命名**：全局替换方法名但担心误伤时，使用 `:%s/oldMethod/newMethod/gc` 逐个审核确认，既安全又高效。
